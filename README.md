\# Plant Leaf Disease Detection



\## Project Overview



This project aims to detect common diseases in tomato plant leaves using image processing and transfer learning.



The model classifies leaf images into four categories:



\- Healthy

\- Tomato Early Blight

\- Tomato Late Blight

\- Tomato Leaf Mold



\## Technologies Used



\- Python

\- Jupyter Notebook

\- TensorFlow

\- OpenCV

\- NumPy

\- Pandas

\- Scikit-learn
